# Omaluxe Candles and Scents

A fully functional e-commerce website for selling premium scented candles and fragrance oils.

## Features

- **Home Page**: Beautiful landing page with hero section and featured products
- **Products Page**: Complete product catalog with category filtering
- **Shopping Cart**: Full shopping cart functionality with quantity management
- **Checkout**: Secure checkout form with order processing
- **About Page**: Information about Omaluxe brand and values
- **Contact Page**: Contact form for customer inquiries
- **Responsive Design**: Mobile-friendly layout that works on all devices

## Product Categories

- Scented Candles (8-12 oz sizes)
- Fragrance Oils (4 oz)
- Gift Sets

## Technologies Used

- HTML5
- CSS3 (Custom styling with CSS Grid and Flexbox)
- Vanilla JavaScript
- LocalStorage for cart persistence

## How to Use

1. Open `index.html` in a web browser to view the website
2. Browse products and add items to cart
3. View cart and proceed to checkout
4. Fill out the checkout form to complete your order

## Pages

- `index.html` - Home page
- `products.html` - Product catalog
- `cart.html` - Shopping cart
- `checkout.html` - Checkout form
- `about.html` - About Omaluxe
- `contact.html` - Contact form
